**Kanban** — это консольное приложение для управления задачами по методологии Kanban.  
Позволяет создавать задачи (`Task`), эпики (`Epic`) и подзадачи (`Subtask`), отслеживать статусы, приоритеты по времени и автоматически сохранять данные в CSV-файл.

### Основные возможности:
- ✅ Создание, обновление, удаление задач, эпиков и подзадач
- ⏱ Автоматический расчёт времени эпика (startTime, endTime, duration) на основе подзадач
- 📊 Приоритезация задач по времени начала (`TreeSet` + компаратор)
- 💾 Автосохранение в CSV-файл с возможностью восстановления
- 📜 История просмотров задач (связный список)
- 🚫 Проверка пересечения задач по времени
